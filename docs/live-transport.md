# HermesLink 实时看板

手机工作区的「看板实时动态」显示服务器状态、看板任务数和最新 80 条看板事件。事件列表显示类型、任务编号和时间。看板须在所选配置档案启用。初次连接从看板当前末尾开始，断线后重新连接使用该订阅已收到的游标。退出页面、切换看板或退出登录时释放订阅，退到后台时断开连接。

| Windows 安装版 v0.23.2 接口 | 服务端前提与手机入口 |
| --- | --- |
| `POST /api/auth/ws-ticket` · `/api/plugins/kanban/events` | 已登录的 Webapp 请求取得一次性票据，连接校验同源和看板插件状态。手机以只读方式订阅选中的看板。 |
| `/api/events` · `/api/pub` | Webapp 和独立仪表板的嵌入式聊天共用这组路由。事件订阅和发布使用同一个 PTY channel，发布端可使用服务端生成的内部凭据。手机的普通会话通过已附接的 `/api/ws` 会话和 `session.events.since` 恢复事件。主机终端使用自己的附接票据。 |
| `/api/pty` | Webapp 和独立仪表板的嵌入式 Hermes TUI 使用专用 PTY、频道和附接流程。原生 Windows 缺少该 POSIX PTY 后端。手机主机终端通过 `/api/host-terminal` 接入支持 Windows 的主机终端通道。 |
| `/api/console` | Webapp 和独立仪表板提供带独立帧格式和命令确认的控制台。手机的运维页调用具体业务接口。 |
| `/api/display/ws` | 机器人桌面运行后，`display.observe` 为当前配置档案签发单次、短时 RFB 观看票据。手机可从实时看板打开只读画面。手机发送握手和画面请求，服务端的键鼠控制仍由租约约束。 |
| `/api/relay/{connection_id}/{path:path}` | 这是 Webapp 保存的网关连接使用的中继。HTTP 请求仅可到该连接的许可路径，WebSocket 还需要绑定当前浏览器登录的一次性中继票据。手机连接当前登录的 Hermes 服务。 |

## 授权流程

- 模型提供方的设备码流程由官方页面创建会话，按服务端给出的验证地址和用户码交给系统浏览器，再按对应提供方和配置档案轮询。外部 CLI 类型使用提供方规定的工具。v0.23.2 的通用 `submit` 路由拒绝提交。
- MCP OAuth 根据已配置的 HTTP MCP 服务返回授权地址。系统浏览器完成服务端登记的回调，官方页使用对应流程 ID 读取结果或取消。回调地址须满足提供方的注册和网络要求。
- 记忆服务的 OAuth 路由取决于安装的插件。上游启动在运行 Hermes 的主机上打开浏览器并等待其回环回调。
- 已保存网关的 OAuth 由 Webapp 的连接页面和专用回调处理，按当前连接与授权状态建立会话。

## 群聊

新建群聊前，App 读取当前登录和配置档案获准加入的成员名单。新建支持 2 到 6 个同网关的配置档案。发送支持带事件标识和线程标识的纯文本。发送、继续、重试和丢弃需要群聊驱动处于运行状态，并由用户确认。App 用同一条网关连接读取能力并提交操作，所属房间和执行权限由服务器检查。

隔离验收使用合成成员与临时数据库验证新建、驱动未运行时的拒绝、配置档案不匹配时的拒绝、纯文本事件入库与重放时的去重。模型执行以测试组件代替。

## 验证

用 Windows 商店包 v0.23.2 的 Webapp 和隔离测试数据，在本机连接验证取票、只读实时事件、重复使用票据被拒和按游标补读。JVM 网络测试验证手机请求中的登录凭据和源地址，以及事件上限、无效帧和会话取消。生产实例的看板插件启用状态由该实例决定。

机器人桌面通过 RFB 3.8 的原始像素编码显示，支持最多 4,194,304 像素。观看入口在服务器报告桌面运行后显示。退出页面、退到后台或登录变更会关闭连接并清空画面。隔离验收使用合成画面，在安装版 Webapp 验证了官方观察票据、RFB 转发和已消费票据被拒。JVM 同时检查了原始像素、窗口变化、分辨率上限和请求消息范围。 [RFB 协议规范](https://www.rfc-editor.org/rfc/rfc6143.html)
